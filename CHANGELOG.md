# Changelog

## 2.0.1

- Added a localhost Streamlit application for CAMUS and uploaded cases.
- Added reusable inference services for ED/ES case analysis.
- Added runtime artifact validation and downloadable case reports.
- Added an orchestrator tab to run YAML experiments from the localhost.
- Added local-only Streamlit configuration bound to 127.0.0.1.
- Added Windows launchers, setup documentation, and a localhost validation script.
- Restricted diagnosis-driven processing families to robust deviations (|z| >= 2).

## 2.0.0

- Reconstructed project as an independent hierarchical pattern-recognition package.
- Added global, anatomical, and myocardial-textural representations.
- Added masked GLCM plus GLRLM, GLSZM, GLDM, NGTDM, and LBP.
- Added leakage-safe nested patient-group validation with Logistic Regression and Random Forest.
- Added late-fusion meta-classifier and level-specific scores.
- Added view-specific Good References and hierarchical diagnostics.
- Added diagnosis-conditioned adaptive processing and `J_G + J_M + J_T` objective.
- Added reproducible nested patient subsets and YAML experiment orchestration.
- Added automatic feature audits, tests, reports, and migration documentation.

- Added dataset-specific patient order files to prevent synthetic/CAMUS order collisions.
- Added safe fold-local ANOVA scoring for constant features.
- Added explicit IBSI/PyRadiomics validation caveat for custom radiomics matrices.
- Added implementation summary and project tree documentation.
